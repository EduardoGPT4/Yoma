# Yoma 3.2.29

## YomaTV

- **Un gesto atrás basta para salir de un episodio:** en Android 16, con el video a pantalla completa, había que hacer el gesto tres veces.
  - El gesto cerraba primero, sin que se viera, el reproductor y la lista de episodios que estaban debajo; solo el tercero quitaba la pantalla completa.
  - Ahora un gesto quita la pantalla completa y el siguiente cierra el episodio. También vale para el lector de YomaShi.
  - Las páginas ya no se encogen mientras arrastras el gesto; el resto de transiciones no cambia.
