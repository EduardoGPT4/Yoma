# Yoma

Aplicación Flutter basada en YomaShi, con selector Manga/Anime, cuenta MAL desde el inicio y YomaTV integrado con descargas y reproductor Android nativos.

- APK local: [dist/Yoma-prueba.apk](dist/Yoma-prueba.apk).
- [Compatibilidad, almacenamiento y puente MAL](docs/yoma/COMPATIBILIDAD.md).
- [Verificación de anime nativo](docs/yoma/ANIME-NATIVO.md).
- [Diagnóstico de las pruebas originales](docs/yoma/DIAGNOSTICO-PRUEBAS.md).
- [Vista del selector](docs/yoma/selector.png).

El APK de prueba usa app.yomashi.reader.qa. El identificador de producción se conserva. No se publicó en GitHub. El puente MAL está desplegado en YomaTV; requiere una cuenta web previamente vinculada al mismo ID MAL.

Imágenes originales: assets/branding/1-Anime.png, 2-Manga.png y 3-AniManga.png. Diagnóstico y propuesta de autenticación: docs/yoma/DIAGNOSTICO-PUENTE-MAL.md. La versión 2.9.2 aplica la nueva identidad visual; el ajuste de autenticación está pendiente de implementar.
